โครงหน้าเว็บมาจาก https://www.ongkharakgames48.swu.ac.th/ แล้วปรับเป็นแบรนด์ปทุมวันเกมส์

## วิธีเปิด

ดับเบิลคลิกไฟล์ `index.html` ก็เปิดได้ หรือจะรันเซิร์ฟเวอร์ภายในเครื่องก็ได้:

```bash
python3 -m http.server 5500
```

แล้วเปิด http://localhost:5500

```

assets/                         รูปภาพ/ฟอนต์จากเว็บต้นฉบับ (ย่อขนาดแล้ว)

js/api.js                       ชั้นเชื่อมต่อข้อมูล (Google Sheet, API ข่าว, แคช, คำนวณสรุปเหรียญ)
```

โดย `layout.js` เป็นตัววาด header/footer และสคริปต์ใน `js/pages/` เป็นตัววาดเนื้อหา

## ผลการแข่งขันและเหรียญจาก Google Sheet

เจ้าหน้าที่กรอกผลใน Google Sheet แล้วหน้าเว็บอ่านไปแสดงเอง ไม่ต้องแก้โค้ดหรือมีเซิร์ฟเวอร์
สรุปเหรียญทุกหน้าคำนวณจากคอลัมน์ "เหรียญ" ในแท็บผลการแข่งขัน จึงกรอกเหรียญแค่ที่เดียว

### ตั้งค่าครั้งแรก

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ มี 2 แท็บชื่อ `ตารางการแข่งขัน` และ `ผลการแข่งขัน`
   แถวแรกของแต่ละแท็บเป็นหัวคอลัมน์ตามตารางด้านล่าง (นำเข้าจาก `google-sheet/*.csv` ได้: ไฟล์ > นำเข้า)
2. ไฟล์ > แชร์ > **เผยแพร่ทางเว็บ** เลือกแท็บ `ตารางการแข่งขัน` และรูปแบบ **ค่าที่คั่นด้วยจุลภาค (.csv)** แล้วกดเผยแพร่ คัดลอกลิงก์
3. ทำซ้ำกับแท็บ `ผลการแข่งขัน`
4. ใส่ลิงก์ทั้งสองใน `js/config.js`:
   ```js
   sheet: {
     matchesCsv: 'https://docs.google.com/spreadsheets/d/e/.../pub?gid=0&single=true&output=csv',
     resultsCsv: 'https://docs.google.com/spreadsheets/d/e/.../pub?gid=123456&single=true&output=csv',
   ```
5. ตั้งสิทธิ์แชร์ไฟล์เป็น "จำกัด" (ไม่ต้องเปิด "ทุกคนที่มีลิงก์") ให้สิทธิ์แก้ไขเฉพาะเจ้าหน้าที่ และเปิดยืนยันตัวตนสองชั้นในบัญชี Google
   การเผยแพร่ทางเว็บเปิดเฉพาะ 2 แท็บที่เลือก แท็บอื่นในไฟล์ไม่ถูกเผยแพร่
   **ห้ามใส่ข้อมูลส่วนบุคคล** (เลขบัตร, เบอร์โทร, วันเกิด) ในแท็บที่เผยแพร่ เพราะทุกคนอ่านได้

แก้ข้อมูลแล้ว Google ใช้เวลาประมาณ 5 นาทีกว่าจะอัปเดตลิงก์ที่เผยแพร่ และเว็บเก็บแคชในเบราว์เซอร์อีก 2 นาที (`sheet.cacheMinutes`)

## ความปลอดภัย

- **Content-Security-Policy** (meta ในทุกหน้า): รันสคริปต์ได้เฉพาะไฟล์ในเว็บนี้ สคริปต์ที่ถูกแทรกเข้ามา (XSS) และ `onclick=` แบบ inline จะไม่ทำงาน
  จึงห้ามเขียน `<script>...</script>` หรือ `onclick="..."` ในหน้า ให้ใช้ไฟล์ `.js` และ `addEventListener` แทน
- **Tailwind เก็บไว้ในเว็บเอง** (`js/vendor/tailwindcss-3.4.17.js`) ไม่โหลดจาก CDN ภายนอก
- **ลิงก์/รูปจาก API หรือไฟล์ข้อมูล** ผ่าน `UI.safeUrl()` (กัน `javascript:` / `data:`) และ iframe ผ่าน `UI.embedUrl()` (เฉพาะ YouTube / Google Maps แบบ https)
  ถ้าจะฝังจากเว็บอื่น ให้เพิ่มโดเมนทั้งใน `EMBED_HOSTS` (`js/layout.js`) และ `frame-src` ของ CSP
- **ลิงก์เปิดแท็บใหม่** ใช้ `UI.NEW_TAB` (`rel="noopener noreferrer"`)
- **API** ต้องเป็น `https://` ไม่ส่งคุกกี้ และตรวจว่าได้ JSON รูปแบบ `{ data: [...] }`
- **Google Sheet** รับเฉพาะลิงก์ `https://docs.google.com/spreadsheets/...` ไม่ส่งคุกกี้ และทุกข้อความจาก Sheet ผ่าน `UI.esc()` ก่อนแสดง (ใส่ HTML/สคริปต์ใน Sheet จะแสดงเป็นข้อความธรรมดา)
- **กันการฝังหน้าเว็บใน iframe ของเว็บอื่น** (clickjacking) ใน `js/layout.js`
- **`vercel.json`** ส่ง header ความปลอดภัยฝั่งเซิร์ฟเวอร์ (CSP, `frame-ancestors`, HSTS, `X-Frame-Options`, `nosniff`)
  ถ้า deploy ที่อื่น ให้ตั้ง header เดียวกันในโฮสต์นั้น

## สิ่งที่ต่างจากเว็บต้นฉบับ

- หน้าผลการแข่งขันและสรุปเหรียญในเว็บเดิมฝังระบบ Blazor ผ่าน iframe จึงสร้างหน้าเหล่านี้ใหม่ด้วย JS
  โดยอ่านข้อมูลจาก Google Sheet (ดูหัวข้อ "ผลการแข่งขันและเหรียญจาก Google Sheet")
- หน้าเพลงประจำการแข่งขัน: ไม่ได้คัดลอกเนื้อเพลงและคอร์ดมา ถ้าต้องการแสดง ให้ใส่ใน `SiteData.anthem.lyrics`
  ที่ `js/data/content.js` แล้วหน้าเว็บจะแสดงให้เอง
- ระบบลงทะเบียนนักกีฬา (ระบบหลังบ้าน) อยู่ในโฟลเดอร์ `registration/` รันแยกด้วย Node.js ดูวิธีใช้ใน `registration/README.md`
- "ระบบลงทะเบียนนักกีฬา" ในเมนูยังไม่มีลิงก์ (แสดงในเมนูเป็นข้อความสีจาง กดไม่ได้) ใส่ลิงก์ได้ที่ `href` ของเมนู `register` ใน `js/config.js`
- หน้าแรกจัดโครงตามแม่แบบ sports-site-template: กรอบรูป Hero (`SiteConfig.heroImages`), นับถอยหลัง (`SiteConfig.startDate`), ชนิดกีฬา + ค้นหา และแถบผู้สนับสนุน (`SiteData.sponsors` ใน `js/data/content.js`) ตอนนี้เป็นกรอบเปล่า/ชื่อตัวอย่าง รอใส่ข้อมูลจริง
- หน้านโยบายความเป็นส่วนตัว (`privacy.html`) และเงื่อนไขการใช้งาน (`terms.html`) เขียนใหม่สำหรับปทุมวันเกมส์ โดยอิงหัวข้อจากเว็บคำมอกหลวงเกมส์ ครั้งที่ 49 แก้เนื้อหาได้ที่ `js/data/legal.js`
- หน้า `/schedule` และ `/results` ในเว็บเดิมเป็นข้อมูลตัวอย่าง (ทีมสมมติ) และไม่มีในเมนู จึงไม่ได้สร้าง
